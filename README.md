# Expense Tracker

A simple and responsive Expense Tracker built using HTML, CSS, and JavaScript.

## Features

- Add expenses
- Delete expenses
- Real-time balance calculation
- Data stored using localStorage
- Responsive user interface
- Simple and clean design

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Folder Structure

```bash
expense-tracker/
│
├── index.html
├── style.css
├── script.js
└── README.md
```

## How to Run

1. Clone the repository

```bash
git clone https://github.com/Sanju1203/expense-tracker.git
```

2. Open the project folder

3. Run `index.html` in your browser

OR

Use the VS Code Live Server extension.
